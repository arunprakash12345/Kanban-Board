# Kanban Board

A simple Kanban board built with HTML, CSS, and JavaScript to manage daily tasks in a clean and organized way.

## Features

- Create tasks with title, description, and priority
- Four priority levels:
  - Very High
  - High
  - Medium
  - Low
- Drag and drop tasks between lanes
- Edit existing tasks
- Delete tasks
- Filter tasks by priority
- Task count for each lane
- Data saved in local storage
- Toast messages for actions like create, update, and delete

## Tech Stack

- HTML
- CSS
- JavaScript
- Local Storage
